Added a “Website response Headers” tool served by Worker HTML routes (not a static tool page), with a backend API that fetches the target URL server-side and returns response headers:
- Page routes: `/tools/website-headers` (default lang) and `/<lang>/tools/website-headers` (e.g. `/en/tools/website-headers`)
- API: `/api/tools/website-headers?url=...` → JSON with `status` / `finalUrl` / `headers`
- Safety: http/https only; block localhost and private ranges (127.0.0.1, 10.0.0.0/8, 192.168.0.0/16, 172.16.0.0/12, ::1, fc00::/7, fe80::/10, etc.) to reduce SSRF risk
- i18n: Chinese/English copy and language switcher; languages as an extensible list
- Defaults in `wrangler.jsonc`: `SITE_DEFAULT_LANG` (default `zh`) and `SITE_LANGS` (default `zh,en`)

Also cleaned the home page: removed all `href="#"` placeholder cards; kept existing Markdown → HTML; added link to `/tools/website-headers` (English: `/en/tools/website-headers`).
