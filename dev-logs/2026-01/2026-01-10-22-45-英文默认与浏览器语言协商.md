设置英文为默认语言，并且判断浏览器可接受语言作为页面语言，网站没有对应语言则显示英文

[try to solve]
Two-layer language selection:

1) Worker (dynamic routes)
- Default fallback language English (`SITE_DEFAULT_LANG=en`).
- For Worker-rendered HTML (e.g. tool routes), pick the best match from `Accept-Language`; if unsupported or disabled, fall back to English.

2) Static pages (home / devlogs)
- Platform may serve static assets first, so every generated page injects an early `<head>` script that:
  - Reads `navigator.languages` (or `navigator.language`) and picks the best site language;
  - If the URL has no lang prefix and English is chosen, navigates to `/en/...`;
  - Falls back to English when the browser language is not a site language.
