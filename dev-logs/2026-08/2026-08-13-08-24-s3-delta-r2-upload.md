Implemented remote R2 publish acceleration:

1. **S3 direct upload** (default): when `R2_ACCOUNT_ID` + `R2_ACCESS_KEY_ID` + `R2_SECRET_ACCESS_KEY` are set, use `@aws-sdk/client-s3` for in-process concurrent PutObject (default concurrency 32); without credentials, fall back to wrangler (slow, with warn). Force with `--s3` / `--wrangler`.
2. **Delta**: `npm run upload:r2:changed` (`--changed-only`). Meta `schemaVersion: 2` includes `fileHashes`; compare R2 meta → local `.cache`; missing old hashes means full upload. Still rewrites `_meta/pages-build.json`.
3. Docs: `ops/worker-r2-ops.md` §3.1; `ops/README.md`; `cloudflare-workflow.mdc`.

Usage:
```bash
export R2_ACCOUNT_ID='...'
export R2_ACCESS_KEY_ID='...'
export R2_SECRET_ACCESS_KEY='...'
npm run upload:r2           # full S3 upload
npm run upload:r2:changed   # changed files only
```
