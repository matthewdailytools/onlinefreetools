已实现远程 R2 发布加速：

1. **S3 直传**（默认）：有 `R2_ACCOUNT_ID` + `R2_ACCESS_KEY_ID` + `R2_SECRET_ACCESS_KEY` 时用 `@aws-sdk/client-s3` 进程内并发 PutObject（默认并发 32）；无凭据回退 wrangler（慢，会 warn）。可用 `--s3` / `--wrangler` 强制。
2. **增量**：`npm run upload:r2:changed`（`--changed-only`）。meta `schemaVersion: 2` 含 `fileHashes`；对比 R2 meta → 本地 `.cache`；无旧哈希则全量。仍重写 `_meta/pages-build.json`。
3. 文档：`ops/worker-r2-ops.md` §3.1；`ops/README.md`；`cloudflare-workflow.mdc`。

用法：
```bash
export R2_ACCOUNT_ID='...'
export R2_ACCESS_KEY_ID='...'
export R2_SECRET_ACCESS_KEY='...'
npm run upload:r2           # 全量 S3
npm run upload:r2:changed   # 只传变更
```
