Catching “new phrases” and “fresh events” is not one magic tool; it is multi-source signals → dedupe/cluster → check real search/use.

## 1. New phrases (language layer)

| Source | What to watch |
|------|--------|
| **Search autocomplete** | Google / Bing / YouTube / TikTok suggestions and “people also search” |
| **Google Trends / Keyword Planner** | Rising and breakout terms, related queries (worth following only with search volume) |
| **Social hot lists** | X/Twitter, Reddit, Xiaohongshu, Weibo hot search; how tags and memes get restated |
| **Dictionaries / corpora** | Urban Dictionary, Wiktionary new entries, news corpora per language |
| **Professional circles** | GitHub Trending, Product Hunt, Hacker News; industry newsletters |

Bar: the same wording appears on ≥2 independent channels and maps to an executable task (calculate / convert / generate / validate) before it enters the keyword pool.

## 2. Fresh events (event layer)

| Source | Use |
|------|------|
| **News aggregation** | Google News, BBC/Reuters RSS, Chinese portal hot lists |
| **Official / regulatory** | Government and standards announcements (policy and standard names often mint new terms) |
| **Product launches** | Apple/Google/OpenAI changelogs, WWDC/Google I/O |
| **Data anomalies** | Sudden new queries in GSC, new landing pages in Analytics |

An event is not a topic by itself; break it into: what action does this make the user need? Then enter the funnel.

## 3. Practices that fit this site

Existing keyword-to-tool flow: ~10 daily terms into keyword-daily-pool, then absorb / build / defer.

Keep three “freshness” pipes, scanned weekly:

1. New GSC queries (new wordings already hitting this site) → prefer absorb
2. Trends + Planner rising long-tails (avoid head-on head terms; watch long_gap / locale_gap)
3. New verb phrases from social/HN/product launches → keep only “browser-doable tool” intent

Flow remains: SERP summary → pool → compare catalog for absorb/build; do not create a page on every new phrase.

## 4. Low-cost habits

- Daily 15 minutes: hot lists/HN + this site’s new GSC queries
- Weekly once: Trends “past 7 days” rising + Keyword Planner related terms
- Log template: new wording / first channel seen / user task / existing slug? / search signal?

Much “fresh” is noise; verifiable search intent + interactive task + SERP gap are the new phrases worth catching.
