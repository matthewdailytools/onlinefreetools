Summary: Fix localhost image-crop 404 by seeding local R2.

[question]
找不到 localhost 的网页 http://localhost:8787/zh/tools/image-crop

[try to solve]
原因：只用了 `npm run dev`（wrangler），未把 `public/_pages` 灌进本地 R2；工具页 HTML 权威在 R2，未 seed 则 404。首页可从 Assets 出所以能开。已执行 `npm run upload:r2:local`（1540 个对象），复查 `http://127.0.0.1:8787/zh/tools/image-crop` 返回 200 且含 How `<ol>`。建议日常用 `npm run start:dev`（含 build + seed）。

[actions]
- npm run upload:r2:local
