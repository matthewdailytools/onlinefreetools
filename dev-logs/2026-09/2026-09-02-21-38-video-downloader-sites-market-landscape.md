## Context
Competitive / landscape research: which public products currently offer web (or closely related) downloaders for YouTube, TikTok, Instagram, and other sites.

## Process
1. Searched English and Chinese sources for 2025–2026 “online video downloader” roundups and brand pages.
2. Cross-checked frequently named multi-site web products (Cobalt, SaveFrom/SSYouTube, Y2Mate-class clones, Seekin, J2download, VideoFK, DownNi, etc.).
3. Separated platform-specialized TikTok/IG tools (SnapTik, SSSTik, etc.) from “1000+ sites” claims and from desktop yt-dlp GUIs.
4. Noted known caveats: Cobalt official instance often disables YouTube; ad-heavy clone farms; ToS/copyright risk; support lists change when platforms break extractors.

## Root cause / analysis
The market splits into four layers:
1. **Privacy / open-source web** (Cobalt) — fewer sites, cleaner UX, intentional YouTube limits on public instance.
2. **Ad-monetized multi-site web** (SaveFrom family, Y2Mate clones, many SEO mirror domains) — broad claims, high ad/malware risk, unstable domains.
3. **Platform specialists** (SnapTik/SSSTik for TikTok; many IG Reel/Story one-offs) — narrow but fast for one job.
4. **Desktop / local yt-dlp GUIs** — not “websites,” but dominate reliability for YouTube + 1000+ sites.

Chinese SERP often surfaces Seekin, J2download, VideoFK, DownNi with YouTube + TikTok + Instagram + domestic platforms (Douyin, Xiaohongshu, Bilibili, Kuaishou).

## Solution
Delivered a categorized landscape to the user (web multi-site, specialists, CN-oriented sites, desktop counterparts) with “claimed vs durable” caveats. No product built on onlinefreetools.

## Notes / boundaries
- Names and “supports X” claims are marketing-time snapshots; platforms break extractors regularly.
- Research only; not an endorsement to scrape or redistribute copyrighted media.
- Ad-heavy download portals historically pushed malicious ads/fake installers—treat as high-risk UX category.
