## Third completed item

`/tools/batch-convert-mp3-files-to-wav` turns multiple independent MP3s into separate 16-bit PCM WAVs. The queue reports actual input/output bytes, WAV expansion ratio, sample rate and channels; it supports individual downloads, 20 same-name files, partial success, stop/resume and retry. The page explains that PCM WAV usually expands file size and cannot restore details already discarded by MP3. Ten localized titles and opening paragraphs carry the batch MP3-to-WAV intent without a keyword list.

The converter validates MP3 frames before Web Audio decoding, then writes the WAV header and PCM in bounded chunks directly to OPFS for real user files. Browsers without OPFS use a 96 MiB retained-output memory budget. The UI caps each MP3 at 20 MiB/5 minutes, each WAV at 60 MiB, and the queue at 20 files; these are code limits, not all tested maximums.
