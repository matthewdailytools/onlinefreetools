# 网站颜色方案制定指南（本站落地）

Date: 2026-08-08  
Scope: OnlineFreeTools.org 浅色工具站 + 四套可切换品牌主色  

**结论先说：** 颜色方案不是「改一下 `a` 的颜色」。行业常规是 **原始色阶（primitives）→ 语义角色（semantics）→ 组件映射（components）** 三层；换品牌主色时只改 primitives/品牌衍生，组件继续引用语义名。

权威参考（方法同源）：[Primer Color](https://primer.style/foundations/color/overview)、[SGDS Semantic colour](https://designsystem.tech.gov.sg/foundations/colour/semantic-colour)、通用 token 分层实践（primitive / semantic / component）。

---

## 1. 为什么不能只改链接色

| 只改 `a` | 完整方案 |
|----------|----------|
| 页脚/相关工具变色，按钮/焦点/选中仍可能是旧红 | 所有「要品牌感」的点统一跟主色走 |
| 换主题时只有链接跟着变 | 背景微染、选中、焦点、pill、表单 focus 一起变 |
| 错误态若误用品牌色会语义混乱 | **危险/成功等状态色与品牌色解耦** |

本站此前问题：全局 `a { color: accent }` + 单一朱红，把「可点击」和「品牌强调」绑死。正确拆开：**链接默认中性；品牌色只服务行动与状态强调。**

---

## 2. 制定流程（策略）

1. **定品牌主色（Brand Primary）**  
   本站四套：`teal` / `green` / `amber` / `navy`（用户可切换）。
2. **定中性色阶（Neutrals）**  
   灰阶负责可读性与层级，**跨主题尽量固定**（工具站以阅读/操作为主）。
3. **定语义角色（Semantics）**  
   用「干什么」命名：`bg` / `surface` / `text` / `border` / `action` / `focus` / `link` / `danger`…  
   **禁止**在组件里写死 `#e5322d`。
4. **定组件映射（Components）**  
   顶栏、侧栏、卡片、按钮、表单、页脚、选中态各自引用语义 token。
5. **主题切换**  
   只覆盖「品牌衍生 + 可选氛围微染」；中性正文/边框保持稳定。
6. **对比度自检**  
   正文 vs 底 ≥ WCAG AA；主色实心按钮上的字用 `--on-action`（通常白）。

## 3. 模块与元素清单（要覆盖什么）

### 3.1 页面骨架（Chrome）

| 模块 | 元素 | 语义角色 |
|------|------|----------|
| 页底 | `body` / 工具页底 | `--bg` |
| 顶栏 | 背景、底边、品牌字、导航字、下拉 | `--surface` / `--border` / `--text` / `--text-muted` |
| 侧栏 | 背景、项默认/悬停/选中、分组标题 | `--surface` / `--action-soft`（选中浅底，无左侧品牌色条） |
| 页脚 | 说明字、关于等链接 | `--text-muted` / `--link` |
| 主题切换器 | 色点预览 | 各主题 `--brand` |

### 3.2 内容与卡片

| 模块 | 元素 | 语义角色 |
|------|------|----------|
| Hero | 区底、品牌标题 | `--bg-hero` / `--text-strong` |
| Why / 分类块 / 工具卡 | 面、边、标题、描述 | `--surface` / `--border` / `--text*` |
| 分类 pill | 标签 | `--action` + `--action-soft` |
| 相关工具 | 链接 | `--link` / `--link-hover` |

### 3.3 交互与表单

| 模块 | 元素 | 语义角色 |
|------|------|----------|
| 主/次按钮 | 边框式主按钮（本站现状） | `--text` + `--border`；悬停加深；激活可用 `--inverse` |
| 焦点环 | `:focus-visible`、input focus | `--focus-ring`（品牌衍生） |
| 拖放区悬停 | 虚线边、浅底 | `--action` / `--action-soft` |
| 下拉选中 | 项悬停/当前 | `--action-soft` + `--text-strong` |

### 3.4 反馈（与品牌解耦）

| 角色 | 用途 | 本站固定色（不随主题变） |
|------|------|--------------------------|
| `--danger` | 错误、破坏性 | 红系 |
| `--success` | 成功、通过 | 绿系 |
| `--warning` | 警告 | 琥珀系 |
| `--info` | 提示 | 蓝系 |

**原则：品牌主色 ≠ 错误红。** 琥珀主题下错误仍用 `--danger`，避免「整站都在报警」。

## 4. 原则与策略（可执行）

1. **角色优先于颜料**  
   写 CSS 时问「这是表面还是行动？」再选 token，不要问「用哪个蓝」。
2. **品牌色预算克制**  
   主色出现在：CTA 强调、选中指示、焦点、少量 pill/徽章。正文与默认链接保持中性。
3. **一层换肤**  
   `html[data-theme]` 只改品牌 primitives 与氛围微染；组件不写主题分支。
4. **中性托底、品牌点睛**  
   大面积灰白保证工具可读；主题差异靠点缀 + 极淡底色染色，避免四套「整页换色」花哨。
5. **状态色独立**  
   success/warning/danger/info 跨主题共享。
6. **对比与无障碍**  
   选中态用「浅底 + 深字」，避免依赖左侧品牌色条或浅底+同色浅字。
7. **与竞品差异**  
   不再默认跟 iLovePDF 朱红；四套主色拉开辨识，中性骨架可借鉴其灰底可读性。

## 5. 本站色板（按品牌主色制定）

### 5.1 共享中性（四主题共用）

| Token | 值 | 用途 |
|-------|-----|------|
| `--neutral-0` | `#ffffff` | 抬升面 |
| `--neutral-50` | `#f5f5fa` | 页底 |
| `--neutral-100` | `#ececf2` | 更强分隔（可选） |
| `--neutral-200` | `#d6d6df` | 默认边 |
| `--neutral-300` | `#c2c2cc` | 强边 |
| `--neutral-600` | `#47474f` | 次要字 |
| `--neutral-800` | `#33333b` | 正文 |
| `--neutral-950` | `#161616` | 强标题 |

### 5.2 四套品牌主色 → 衍生

| Theme | Brand | Hover | Soft（~10% alpha） | 氛围底（微染） |
|-------|-------|-------|---------------------|----------------|
| `teal` 青石蓝 | `#0F6E8C` | `#0A5570` | `rgba(15,110,140,.10)` | `#F3F7F9` |
| `green` 森绿 | `#0F7A5A` | `#0B5E45` | `rgba(15,122,90,.10)` | `#F3F8F6` |
| `amber` 琥珀橙 | `#C45C26` | `#9A4519` | `rgba(196,92,38,.10)` | `#FAF6F3` |
| `navy` 墨青 | `#1F4E79` | `#163A5C` | `rgba(31,78,121,.10)` | `#F3F5F8` |

衍生规则：

- `--action` / `--brand` = Brand  
- `--action-hover` = Hover  
- `--action-soft` = Soft  
- `--focus-ring` = `rgba(brand-rgb, .35–.45)`  
- `--bg` / `--bg-hero` / `--surface-muted` = 氛围底（主题可感，但不抢内容）  
- `--surface` / 顶栏 / 卡片 = 仍多为 `--neutral-0`（白）保证对比  

### 5.3 语义层（组件只认这些）

| 语义 | 映射 |
|------|------|
| `--bg` | 氛围底 |
| `--surface` | white |
| `--text` / `--text-strong` / `--text-muted` | neutral-800/950/600 |
| `--border` / `--border-strong` | neutral-200/300 |
| `--link` / `--link-hover` | text / text-strong（中性） |
| `--action*` | 当前主题品牌 |
| `--nav-active` | text-strong + action-soft 底（无左边线） |
| `--danger` 等 | 固定状态色 |

### 5.4 本站按钮策略（与 iLovePDF 白底描边一致）

主按钮当前是 **白底 + 中性边 + 深字**，主题切换时：

- 默认：中性边框按钮（不变成实心品牌块，避免四主题「整页变色块」）  
- 悬停：边框加深到近黑  
- **焦点 / 选中指示 / pill / dropzone 激活**：走 `--action`  
若未来要「实心品牌主按钮」，再加 `--btn-solid-bg: var(--action)` 变体即可。

## 7. 验收清单

- [ ] 换主题后：侧栏选中浅底、分类 pill、焦点环、dropzone 悬停随品牌变（选中无左侧品牌色条）  
- [ ] 换主题后：正文、页脚链接、相关工具仍为中性字色（非品牌色刷屏）  
- [ ] 错误提示仍为 `--danger`，琥珀主题下也不改成「品牌橙当错误」  
- [ ] 顶栏/卡片白面在四主题下对比度正常  
- [ ] 硬刷新后主题偏好仍在  

---

## 8. 与「只改 a」的关系

链接色只是语义层里的 `--link` 一项。完整方案还覆盖：表面、边框、行动、焦点、选中、状态、氛围底。本站按第 5 节落地到 `site.css`。
