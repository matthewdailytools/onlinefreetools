## Review 结论（本轮）

1. **计算器（62）**：词根高度同构为 `{概念} calculator` / `how to calculate {概念}`——几乎均为 **head 风险区**；AdWords 应强制展开到单位、人群、场景、公式变体长尾后再 absorb。
2. **图片/PDF（30）**：头词（compress/merge/convert）竞品极强；词根旁的 **格式对、目标体积、布局、隐私（EXIF/GPS）** 更适合作缺口。
3. **开发者/SEO（31+部分 design）**：`hreflang` / `indexnow` / `www dns` / `serp preview` / `json-ld` 等相对更易出 `long_gap`/`locale_gap`。
