Google Keyword Planner 导出与归类。种子覆盖 **OCR 软件/在线识别** 与 **Scan 硬件/扫描转 Word**。

存量近邻：OCR N1 `convert-a-jpg-to-text-with-ocr`（已上线）；批量图 OCR **N1-batch** `batch-convert-jpg-to-text-with-ocr`（已上线，TXT ZIP）；**N4-jpg-batch** `batch-convert-jpg-to-editable-word-with-ocr`（已上线：多图 → 一份可编辑 DOCX）；**N4** `batch-convert-scanned-pdf-to-word-with-ocr`（已上线：扫描 PDF → 一份 Word）。抽字层 `extract-text-from-pdf`（无 OCR）。照片装订 `images-to-pdf` / `images-to-word`（无 OCR）。
