# 产品 P0 场景句（`p0-scene`）

清单 [§0](../../../2026-08-08-tool-inventory-table.md) 五条进攻场景 slug 的 Bing SERP / 相关搜索归档。跨 zip / 电商主图 / App Store 截图 / apple-touch / OG 链接卡，故单独一夹，不拆进 `cidr/` 或 `social-share/`。

| 产品 slug | 本夹种子搜法 |
|---|---|
| `create-zip-file` | create zip file |
| `amazon-main-image-size` | amazon main image size |
| `iphone-app-store-screenshot` | iphone app store screenshot size |
| `apple-touch-icon` | apple touch icon size |
| `open-graph-image-size` | open graph image size |

OG 作业类型草案仍见 [`../social-share/`](../social-share/)。本夹只记 SERP 证据。

**选词权威（人工复核）**：[2026-08-31-p0-scene-longtail-selection.md](./2026-08-31-p0-scene-longtail-selection.md)。脚本生成的 `*-serp.md` 草稿 tier 在 CN Bing 劫持下不可直接立项。

后续 Bing 批次应使用 `bing_serp` v0.3+ 默认（用户搜法 + 独立 context / 剥 `pq`），不要再跑加引号 / 品牌倒置词表。
