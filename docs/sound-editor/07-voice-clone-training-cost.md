# 07 — 声音训练仿声与歌曲仿声的训练成本

**日期**：2026-09-09  
**状态**：成本说明（数量级）；**不是**报价单、不是立项  
**关联**：[04 三档变声](./04-three-kinds-of-voice-change.md) · [03 V1/V2 栈](./03-voice-conversion-from-speaker-samples.md) · [06 分层](./06-demand-difficulty-cost-roadmap.md)

本篇只回答：**为「某一个人 / 某一种唱法」训出可用模型，要花多少钱、多少时间和多少数据。**  
不回答「从零训一个 CosyVoice 级底座」（那是另一笔 5–7 位数的研究账）。

数字是 **2026 年社区与公开价的数量级**。GPU 租价按周波动；**人时和数据往往比 GPU 贵一个数量级**。标 `社区` 的是爱好者实测，不是厂商 SLA。

---

## 0. 先分清在训什么

「仿声训练」不是一种账单。

| 作业 | 输入 | 输出 | 本篇章节 |
|---|---|---|---|
| **说话训练仿声** | 目标人 **干净口播** | 说话 VC 或 说话 TTS（用他的声音读新稿） | §2 |
| **歌曲仿声（AI Cover / SVC）** | 目标人 **干声演唱**（或高质量人声轨） | 把别人唱的歌 **换成他的音色** | §3 |
| **歌声合成（SVS）** | 歌词 + 音高（MIDI） | 从零唱出来，不必先有一首别人的干声 | §3.4 |
| **零样本 / Instant** | 几秒到几分钟参考 | **不训练权重**，只提 embedding | GPU 训练成本 ≈ **0** |

和 04 对齐：

- **V1**（OpenVoice 等）：不按人训练。成本在推理，不在训练。  
- **V2**（RVC / So-VITS-SVC 等）：**按人 fine-tune**。本篇的「训练成本」主要指这一档。  
- **商业 PVC**（如 ElevenLabs Professional Voice Clone）：你付订阅，他们在自有 GPU 上 fine-tune；**官方写明 PVC 目前不支持唱歌**。

## 1. 成本科目（不要只看 GPU 小时）

一笔「训一个声音」的真实账单：

```
总成本 ≈ 数据获取 + 清洗切片 + GPU 训练 + 失败重跑 + 人验收
        + （可选）授权/法务 + 模型存储与推理
```

| 科目 | 通常占比 | 说明 |
|---|---|---|
| **数据** | 往往最大 | 棚录、从成片扒干声、分轨、去混响、统一麦和风格 |
| **人时** | 第一颗声音很大 | 环境、切片、听测、调 epoch；熟手会下降 |
| **GPU** | 单人 V2 **常常 < $5** | 4090 上 RVC 常 **不到 1 小时** |
| **失败重训** | 1–3 倍 GPU | 数据脏、过拟合、音域没覆盖 |
| **法务** | 名人/商用时主导 | 未授权则不应训 |

云 GPU 锚点（公开价，**2026-07 前后**，用前请再查控制台）：

| GPU | 粗价 | 来源 |
|---|---|---|
| RTX 4090 | 约 **$0.34/h**（RunPod Community）～ **$0.74/h**（Secure） | [RunPod pricing](https://www.runpod.io/pricing) |
| 同级消费卡（国内/市场） | 常见大约 **$0.20–0.55/h** 或人民币每小时数元 | Vast 等市场价会变 |
| A100 80GB | 大约 **$0.7–1.5/h** 量级 | 单人 RVC **用不到** 这档 |

本篇算 GPU 费时用 **$0.40/h · 4090 等价** 做中位，便于心算。

## 2. 说话训练仿声

### 2.1 三条技术档（成本差两个数量级）

| 档 | 数据 | 是否更新权重 | 像度（说话） | 训练 GPU |
|---|---|---|---|---|
| **Instant / 零样本** | 5 秒–5 分钟参考 | 否 | 能认、情绪弱 | **$0** |
| **少样本 fine-tune**（GPT-SoVITS、部分 CosyVoice/F5 LoRA） | **约 1 分钟** 起；10–30 分钟更稳 | 是，小 | 明显高于零样本 | **数分钟级** |
| **专用 VC（RVC v2）** | **10–50 分钟**（官方 FAQ 口径）；精品 5–10 分钟也可 | 是 | 说话/翻唱都常用 | **十几分钟–1 小时**（4090） |
| **商业专业克隆 PVC** | 官方建议 **至少 30 分钟，靠近 1–3 小时** | 是，在厂商侧 | 口播接近本人 | 用户侧等 **约 2–6 小时**（不另开 GPU 账单） |

依据：

- RVC 官方 FAQ：训练集 **约 10–50 分钟**；高质量且音色鲜明时 **5–10 分钟** 也可；**< 1 分钟** 基本没成功案例可复现。[NVIDIA_RVC FAQ](https://huggingface.co/secretguest/NVIDIA_RVC/blob/main/docs/en/faq_en.md)  
- 社区汇总（2026）：10 分钟数据、200 epoch，**4090 约 12 分钟、3090 约 18 分钟、3060 约 35 分钟、Colab T4 约 40 分钟**。另有 Docker 文档写 8–12 小时——多半是小 batch、弱卡或 IO 打满，当作 **上限** 而不是 4090 常态。  
- GPT-SoVITS：宣传 **1 分钟 few-shot**；有实测 RTX 3080 上约 1 分钟音频：SoVITS 8 epoch ~78 s，GPT 15 epoch ~60 s。VRAM：全量 ~14 GB，LoRA ~8 GB。  
- ElevenLabs PVC：最少约 30 分钟，建议 **1 小时、最好接近 3 小时**；**只接受说话，不支持唱歌**；Creator 档起（约 **$22/月**，含 1 个 PVC 槽）。[PVC 文档](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning) · [定价](https://elevenlabs.io/pricing)

### 2.2 自训一颗「说话 RVC」的钱（单人、数据已干净）

假设：10 分钟干净单说话人、200 epoch、4090。

| 项 | 数量级 |
|---|---|
| GPU 墙钟 | **0.2–1 h**（4090 常态）；弱卡 **1–12 h** |
| GPU 租金 | **$0.1–1**（4090）；弱卡 **$1–8** |
| 预训练底模下载 | 一次，约数 GB，可摊到所有声音 |
| 检查点体积 | 推理包常见 **几十–150 MB** 量级 |

**结论：说话 V2 的电费可以忽略。** 你付的是数据和耳朵。

### 2.3 数据与人时（说话）才是大头

| 数据从哪来 | 人时（第一颗） | 额外现金 |
|---|---|---|
| 用户按稿棚录 15–40 分钟 | 录 1 h + 切 0.5–2 h | 麦和房间；可 $0 |
| 播客/会议切片 | 听选 2–8 h | 可能要降噪 |
| 从视频抽音再切 | 3–10 h | 分轨工具时间 |

按内部工时 **$40–80/h** 粗算：第一颗声音 **$80–600 人时** 很常见；第十颗可降到 **$40–150**（流程熟了）。  
GPU 仍是 **几美元以内**。

### 2.4 说话 TTS 克隆 vs 说话 VC

| | 训完能做什么 | 训练贵在哪 |
|---|---|---|
| **VC（RVC）** | 必须再给「源音频」（你说/你唱），改音色 | 数据要覆盖音素；唱歌音域另说 |
| **TTS 克隆（GPT-SoVITS / 商业 PVC）** | **打字出声**，不必先有那句话的波形 | 数据要覆盖读法、语言；PVC 要时长 |

产品上「用我的声音读稿」走 TTS 克隆；「把这段录音变成他」走 VC。两套都可以叫仿声，**训练集约和 GPU 不完全共用**。

### 2.5 商业「买训练」而不是自训

| 产品 | 你付什么 | 得到什么 | 训练对你可见的等待 |
|---|---|---|---|
| Instant clone（多数厂） | 约 **$6–10/月** 起 | 短参考，质量够玩 | 秒–分钟 |
| ElevenLabs PVC | 约 **$22/月** 起 + 额度 | 1 个专业说话克隆 | **数小时** |
| 额度内 TTS | 按字符/分钟从订阅扣 | 与训练费分开 | — |

自训 RVC **不会**自动得到「打字出声」；要再接 TTS 或先 TTS 再 VC（双份伪影）。

## 3. 歌曲仿声的训练成本

歌曲仿声有两条完全不同的训练账。

### 3.1 路径 A — SVC / RVC Cover（业界最常见）

流程：

```
目标人干声（唱歌） → 训 SVC/RVC
别人的歌 → 分出人声 → 转换成人目标音色 → 再贴回伴奏
```

**训练数据必须尽量是干声、少后期、音域尽量拉满。** 用口播数据训出来的模型去翻高音，社区一致反馈会破、会电、会不像。

| 项 | 说话 RVC | **唱歌 SVC/RVC** |
|---|---|---|
| 建议净时长 | 10–50 分钟口播 | **干声演唱 15–40 分钟** 更稳；有人用 ~14 分钟、约 100 条 5–15 s 切片起步 |
| 音域 | 说话音高窄 | **必须覆盖目标要唱的高低音**，否则副歌崩 |
| 切片 | 随便切句 | 官方建议 **5–15 s** 一条，避免 OOM |
| 4090 训练墙钟 | 常 12–40 分钟 | **优化好时可 ~20 分钟（约 9k–11k step）**；IO/小卡可到 **数小时–1 天** |
| 额外一步 | 无 | 几乎总要 **人声分离**（训练前扒干声 + 推理时扒源唱） |

社区锚点：

- so-vits-svc 用户：约 113 条、**14 分钟**干净音频可训；Colab 上 **数小时、约 2k epoch**（弱卡/笔记本路径）。  
- 4090 + 数据进内存：约 **9k–11k step / ~18 分钟** 已能用；过训会机械。  
- 另一例：RTX 4070、约 2k 条、**2 分钟/epoch、777 epoch ≈ 1 天**——说明 **同一算法墙钟可差 50 倍**，取决于 batch、IO、`all_in_mem`、扩散分支开不开。

**GPU 中位（唱歌 V2，数据已切好）：**

| 场景 | 墙钟 | GPU 费（$0.40/h） |
|---|---|---|
| 4090，只训 SoVITS，不开完整扩散 | **0.3–2 h** | **$0.1–1** |
| 开浅扩散 / 小卡 / 未优化 IO | **8–24 h** | **$3–15** |
| 反复重训 3 次（音域不够） | ×3 | 仍常 **< $50** |

**歌曲仿声真正贵的前置：**

| 前置 | 人时 | GPU | 备注 |
|---|---|---|---|
| 从专辑/现场 **分离干声** 当训练集 | 选曲 + UVR/Demucs **2–20 h 人听** | 每小时成片大约 **0.2–1 h GPU** | 版权；合音会污染音色 |
| 推理每一首 Cover | 分轨 + 转换 + 混 | 每首歌 **1–10 分钟 GPU** | **不是训练**，但是产品成本 |
| 请真人按音阶录干声 | 棚时 1–4 h | 0 | 质量远高于扒歌；这是正道 |

扒 10 首歌做训练集：分离+听检 **半天到两天** 很常见，**$200–1500 人时** 轻松超过 GPU。

### 3.2 路径 B — 「用说话模型去唱」

很多人用 **口播 RVC** 直接 Cover。

- **训练成本** ≈ §2（便宜）。  
- **质量成本** 转嫁到听感：中低音尚可，假声/高音/气声差。  
- 若产品承诺「明星唱歌」，这条会省训练费、赔口碑。

### 3.3 路径 C — 商业唱歌克隆（买训练）

| 产品 | 公开价量级（2026） | 训练对用户 |
|---|---|---|
| [Kits.ai](https://www.kits.ai/pricing) | 约 **$10/月** 起有克隆槽；Producer 更高、槽更多 | 含 Instant / Professional 唱歌向克隆 |
| [ACE Studio](https://acestudio.ai/pricing/) | Artist 约 **$16.58/月**（1 个 synth 克隆槽 + 1 个 changer 槽）；Pro **$22/月**（更多槽） | 唱歌合成 + 变声槽；订阅含重训次数（以官网为准） |
| ElevenLabs PVC | 见上 | **明确不训练唱歌** |

对「只训几个自己的声音」：**订阅 $10–25/月 通常比自建 GPU 机房便宜**，因为你买的是流水线和听感，不是 4090 小时。

自建开始划算的拐点：要训 **很多** 授权音色、要模型文件出境、或要离线/私有化。即便那时，**GPU 仍不是大头**。

### 3.4 路径 D — 歌声合成 SVS（MIDI+词）

和 Cover 不是同一训法：学的是「这人怎么唱音高和字」，不是「把已有唱腔换皮」。

- 开源（DiffSinger 等）：数据要 **音高对齐的唱段**，标注贵；单说话人可用几天 GPU，但 **工程+标注** 常是 **人周**。  
- 商业（ACE 等）：按月买槽，把训练藏进订阅。  

SVS 的训练成本 **高于** 同等数据的 SVC Cover，因为要对齐乐谱/音素；不要用 RVC 的「18 分钟 4090」去估 SVS。

## 4. 并排对照（决策用）

同一目标人、**只计「训出第一版能用的模型」**（数据已合法且已切好）：

| | 说话 Instant | 说话 RVC | 说话 PVC（厂商） | 唱歌 RVC/SVC | 唱歌商业槽 |
|---|---|---|---|---|
| 数据 | 秒–分钟 | 10–50 分钟口播 | 0.5–3 小时口播 | 15–40 分钟 **干声演唱** | 按各厂（常十几分钟起） |
| GPU（自训） | 0 | **$0.1–8** | 含在订阅 | **$0.1–15**（4090–弱卡） | 0（厂商侧） |
| 人时第一颗 | 0.1–0.5 h | **2–8 h** | 上传+过检 0.5–2 h | **4–16 h**（含分轨听检） | 0.5–2 h |
| 现金中位（自训） | ~0 | **~$50–400**（几乎全是人） | **$22/月** 档 | **$150–800**（几乎全是人+分轨） | **$10–22/月** |
| 会唱歌吗 | 差 | 能凑合 | **官方不支持** | 这才是正路 | 这才是正路 |

**缩放：**

| 规模 | GPU | 真正爆炸的 |
|---|---|---|
| 1 个自己的声音 | 可忽略 | 第一次流程 |
| 100 个授权配音员 | 100 × $1 ≈ **$100 GPU** | 合同、质检、存储、侵权审核 |
| 10 000 个名人扒歌 | GPU 仍可能 < 五位数 | **权利金与下架**，不是训练费 |

## 5. 不要算进「按人训练」的账

| 项 | 数量级 | 何时才要 |
|---|---|---|
| 从零训内容编码器 / 通用 VC 底座 | 数千–数万小时语音 + 多卡周–月 | 做平台底座；**不要为单个明星付** |
| 推理服务常开 4090 | **$250–550/月** 量级（$0.4/h × 24×30） | 有在线转换流量之后 |
| 每首歌 Cover 推理 | **$0.01–0.20** GPU + 分轨 | 与训练无关，但用户感知「每次仿唱」 |

## 6. 对产品节奏的含义（对照 06）

- W1 的 V0 滤镜：**训练成本 0**。  
- W3「克隆自己」：优先 **Instant / 少样本 TTS**（训练费 ≈ 订阅或数分钟 GPU），不要一上来按 PVC 要 3 小时口播。  
- **歌曲仿声** 不要复用说话 PVC；要么 SVC 自训干声，要么 Kits/ACE 一类唱歌槽。  
- 自建训练集群 **挡不住** 成本：挡得住的是 **干声获取和授权**。06 把未授权明星锁 L4，经济上也成立——扒歌训练集的人时和风险远大于 4090。

## 7. 结论（可对外讲的三句）

1. **训一颗说话 RVC，4090 常常几十分钟、不到一美元电费；10–50 分钟干净口播才是门槛。**  
2. **训一颗能唱歌的模型，GPU 仍然通常是几美元到十几美元；贵的是干声音域和分轨听检，往往几百美元人时。**  
3. **「明星歌曲仿声」的训练费可以很低，权利与数据费可以高到做不成；商业唱歌订阅（约每月十几美元一档）对少量音色通常比自建训练机更便宜。**

出处随厂商改价会过时。拍预算时：**GPU 按 $1–20/人备份；人时按 $100–800/人备份；名人按法务无限。**
