# 09 — 端侧「自备模型翻唱」竞品对照

**日期**：2026-09-09  
**状态**：竞品调研；**不是**立项、未改 `src/`  
**对照产品**：用户自己寻找并导入模型，App 在手机上完成转换和唱歌（BYOM + 本地 SVC）  
**关联**：[06 分层](./06-demand-difficulty-cost-roadmap.md) · [08 端侧仿唱](./08-on-device-celebrity-singing.md)

本篇只画 **用户现在用什么凑出同一作业**。名单会过时；架构分摊（云 Cover / 桌面 RVC / 货架变声 / 文生歌）比单款 App 名更稳。

---

## 1. 先固定「在跟谁比」

作业四格（08 的推荐落地 + 用户确认的产品形态）：

1. **原生手机**（不是 Termux、不是必须插电脑）  
2. **用户文件导入模型**（系统文件 / 分享；**不**做应用内明星货架）  
3. **本地推理**（音频不上转换云）  
4. **唱歌闭环**（干声或分轨 → 转音色 → 叠伴奏 → 导出）

几乎没人四格占满。竞品要按 **用户会拿来替代你的东西** 分组，不要把 Suno、全民K歌、魔音工坊配音和 RVC 翻唱打成一张表。

产品叙事应对齐 06/08：默认能力是 **用户有权使用的模型**（自己训的、授权角色）；不预装名人包；找模型发生在 App **外面**。

---

## 2. 分摊总表

| 摊 | 用户作业 | 代表 | 是否同一赛道 |
|---|---|---|---|
| **A. 导模型 + 变声/翻唱** | 自备或社区 `.pth`/`.onnx`，转换已有人声 | Voice.ai、Echo、Weights、国产 RVC 变声 App、模型工坊整合包 | **直接或半直接** |
| **B. 桌面 RVC 工作台** | 电脑训+推+一键翻唱 | RVC WebUI、Applio、w-okada、Vonovox、so-vits-svc | **隐型主竞品**（便携做不好人就回这里） |
| **C. 云端 AI Cover** | 上传歌、选音色、平台出结果 | Kits.ai、Covers.ai / Voicify、部分 Voice.ai Cover | 作业重叠，**架构相反** |
| **D. 分轨/练习** | 先拆人声伴奏，Cover 另接 | Moises、Lalal.ai | 互补或上游，不是全身 |
| **E. 文生歌 / K 歌 / TTS** | 从字或哼唱长出歌；修音欢唱；配音 | Suno、Udio、MELO、唱作魔方、全民K歌、Smule、十一Labs、魔音工坊 | **不要对标功能清单** |

## 3. A 摊 — 最近的直接对手

| 产品 | 形态 | 和四格的关系 | 备注 |
|---|---|---|---|
| **Voice.ai** | iOS / Android / 桌面；可上传 RVC zip；有 Voice Universe 社区库 | 手机 + 导模型 **最像**；推理/账号偏云；主场景偏实时通话，不是分轨混伴奏工作台 | 商店里最接近的「能导 RVC」App |
| **Weights**（weights.gg + iOS《Weights: AI Voice Covers》） | 社区海量模型 + 浏览器/App 出 Cover；模型也可下 `.pth` 到本地工具 | 需求最像（找模型 + 出 Cover）；**合规最危险**（货架即角色/名人） | 「找模型」被做成平台，正是 08 禁止的应用内目录 |
| **Echo**（voicechanger.live 一类） | 导 `.onnx`，实时变声；常要先把 `.pth` 转 ONNX | BYOM 格式路径最干净；唱歌 Cover 不是主 UI；偏桌面/Mac | 格式策略可学：App 只收 ONNX |
| **魔音变声器青春版** 等国产 RVC 变声 App | 游戏开黑、预设包，部分支持导 RVC | 手机 + 部分 BYOM；作业是 **实时通话**，不是翻唱导出 | 延迟/悬浮窗是他们的杠，不是混音 |
| **MagicMic** 一类 | 内置大量 RVC 风音色 | 货架型，不是文件导入型 | 审核与权利风险与 Weights 同类 |
| **华语 RVC 模型工坊**（如 mxgf.cc 整合包） | Windows 一键：解密/分轨/去混/转换/混音 + 模型下载 | 四格里的 2+3+4 在 **电脑** 上已经打通 | 华语爱好者默认入口；手机要抢的是便携，不是再做一个盗版货架 |

A 摊教训：能上架的「导模型」App 往往同时带 **社区库**；纯文件导入、无货架、以唱歌导出为主的手机产品仍空。

---

## 4. B 摊 — 桌面隐型竞品（不要低估）

手机体验达不到「一键翻唱」，用户会继续用这些，而不是将就一个残缺 App。

| 工具 | 角色 |
|---|---|
| **RVC WebUI**（RVC-Project） | 开源原教旨：训练 + 推理 + 导出 ONNX |
| **Applio** | 训模 + 推理一体，社区常用前端；Android 有 Termux 硬跑指南（6GB+ RAM、易崩，不是产品） |
| **w-okada Voice Changer** | 实时变声参数最细（块大小、F0、index） |
| **Vonovox** | Windows + Nvidia，开黑实时 |
| **so-vits-svc** | 更偏唱歌 SVC |

对标体验时：进度 HUD、分轨、变调、叠伴奏应对 **Applio / 模型工坊一键翻唱**，而不是对标 Voicemod 音板。

---

## 5. C / D 摊 — 云 Cover 与分轨

| 产品 | 特点 | 差异化怎么写 |
|---|---|---|
| **Kits.ai** | 授权艺人音色、分轨、母带；约 $10/月起；上架相对干净 | 你：**本机 + 自备模型**；他们：**授权库 + 云**。商店叙事可学「同意/授权」，不要学「100 个艺人货架」除非有合同 |
| **Covers.ai / Voicify** | 上传选音色，短视频 Cover | 快、云、少控制 |
| **Moises / Lalal.ai** | 分轨极强；Cover 常再接转换器 | 可当能力参考（分离质量），不必自研第一年 SOTA 分轨 |
| **ElevenLabs** | 说话克隆强 | PVC **官方不支持唱歌**（见 07）；不是唱歌 Cover 对手 |

用户感知「AI 把歌换成某嗓」时，C 摊和你抢的是 **同一句话**，不是同一套系统。FAQ 必须写清：本 App 不上传歌声做转换。

## 6. E 摊 — 明确划出去

| 看起来像 | 实际作业 | 为何不进对照清单 |
|---|---|---|
| Suno / Udio / MELO / 唱作魔方 | 文生歌、哼唱成曲 | 没有「导入 RVC、换已有唱段的音色」 |
| 全民K歌 / Smule | 正版伴奏 + 修音 | 版权曲库 + DSP 美声，不是 SVC |
| 魔音工坊 | TTS 配音 | 从字出声 |
| Voicemod | 滤镜、音板、游戏整活 | 少量 AI 音色，不是按人训的唱歌生成器 |

混进 E 摊会把产品做成「又一个 AI 写歌」，和 08 的 SVC 流水线无关。

## 7. 空隙与推荐打法

四格里现存组合：

| 组合 | 谁 |
|---|---|
| 手机 + 导模型（+ 常常还有货架） | Voice.ai |
| 手机 + 找模型货架 + Cover | Weights |
| 电脑 + 导模型 + 本地 + 唱歌 | Applio / 模型工坊 / WebUI |
| 手机 + 本地 + 无货架 + 唱歌导出 | **基本空** |

建议对标：

- **体验**：桌面 Applio / 华语模型工坊的一键翻唱（分轨 → 转 → 混 → 出）  
- **商店叙事**：Kits 的「授权/自备」，截图用自己的声音或虚构角色  
- **不要**：ASO 堆歌星名；应用内搜 Hugging Face / 社区明星模型

落地顺序仍见 08 §12：先导入 `.onnx` + 干声导出，再分轨混音；`.pth` 转换可后做或桌面伴侣。

---

## 8. 合规（竞品在做 ≠ 你能做）

Weights、部分变声 App、模型下载站证明 **需求真实**。它们不证明应用内名人目录可过审、可商用。

| 做法 | 本产品 |
|---|---|
| 应用内明星/角色模型商店 | **不做**（06 L4 / 08 §11） |
| 用户从系统文件导入自备模型 | **做**；导入勾选「有权使用该模型与该曲」 |
| 社区目录站当增长入口 | 可在帮助文案写「在电脑上训好或转换后，用文件打开」；**不深链未授权货架** |
| 输出 | 标合成音频 |

「用户自己找的模型，所以与开发者无关」**挡不住** 商店和权利方。元数据与截图决定审核，不决定用户私下导入什么文件。

---

## 9. 结论

- 直接对手是 **Voice.ai（导模+手机）** 和 **Weights（Cover+模型社区）**；华语侧桌面 **模型工坊/Applio** 才是爱好者默认工具。  
- 云 Cover（Kits 等）抢同一用户句子，用相反架构。  
- 文生歌、K 歌、TTS **不是** 本作业竞品。  
- 可打的空隙：**原生手机 + 文件导入 + 本地 SVC + 唱歌导出**，不做名人货架。  

本篇不是上架清单，也不是模型下载黄页。实现栈仍以 08 为准。
