# 10 — 网站「模型站」还有没有空间

**日期**：2026-09-09  
**状态**：策略说明；**不是**立项、未改 `src/`  
**问题**：若做网站托管/分发 RVC·SVC 音色模型，是否还有市场空间  
**关联**：[06 L4](./06-demand-difficulty-cost-roadmap.md) · [08 合规](./08-on-device-celebrity-singing.md) · [09 竞品](./09-byom-singing-app-competitors.md)

09 把 Weights 列为 Cover + 社区库的直接对手。本篇补一句事实：**Weights.gg / Replay 在 2026-04-01 关站**（公开报道：团队与 IP 被 OpenAI 收购，不继续做同类公开产品）。爱好者缺中心库，和「再开一个名人货架是否可做」是两件事。

---

## 1. 一句话结论

**有需求真空，没有「再做一个 Weights」的安全空间。**  
关站空出的是流量和找模型的痛苦，不是一条能干净上架、能长期运营、能挂在 onlinefreetools.org 上的生意。

和 06 对齐：未授权明星/角色模型分发 **D=5，仍锁 L4**。

---

## 2. 关站之后人还去哪找模型

| 角色 | 还在的形态 |
|---|---|
| 存权重文件 | Hugging Face 个人仓库 |
| 当目录搜 | Voice-Models、AIVoices 一类聚合（链到 Drive/HF） |
| 华语一键包 + 下载 | 模型工坊类站点 |
| 口碑和约模 | Discord / Reddit |

目录站普遍：分类乱、假文件、无版本元数据、无「能不能在手机 ONNX 上跑」的标记。从 **体验** 看，再做一个更好找的网站有缝。从 **产品与合规** 看，那条缝填的是 Weights 同构物。

---

## 3. 为什么「更好找的名人库」不能当空间

公开报道把 Weights 的收购解读成：拿掉未授权名人/政客/角色目录这块权利炸弹，而不是把它做成大厂官方克隆商店。后来者铺同样货架，会同时撞：

| 层 | 会怎样 |
|---|---|
| 法务 | 声音权、人格权；训练集还常含未授权录音/歌曲 |
| 支付与云 | 卡组织、对象存储、CDN 的滥用/侵权下架 |
| 配套 App | 网站当货源时，商店审核把两端绑在一起 |
| 本站 SEO | 见 §6：不能挂上 onlinefreetools |

「用户上传的，平台免责」挡不住通知—删除循环，也挡不住你被当成分发枢纽。需求真实 ≠ 可排期（05/06 已写过同一条）。

---

## 4. 按形态看还有没有空间

| 形态 | 空间 | 说明 |
|---|---|---|
| 未授权明星/角色模型站 | **无（不该做）** | 与关停前的 Weights 同构 |
| 再聚合一遍 HF 外链 | 体验有缝、生意没有 | 薄目录；易变成 scaled thin pages |
| 本人同意的原声音色市场 | 有，但已有重玩家 | Kits 艺人库、ElevenLabs Voice Library / Iconic；门槛是合同和分成 |
| **只托管「我自己的模型」** | **有** | 私有库、过期链接、团队分享；像带校验的网盘，不是淘宝 |
| **手机可用的包装层** | **有，且贴 BYOM App** | 识别 v1/v2、采样率、F0；`.pth`→`.onnx`；听测；拒绝不明图 |
| 授权角色 / 虚拟声线 | 有条件有 | 配音员、原创角色；必须核验身份，不能靠搜艺人姓名 |

Weights 关掉后更缺的是 **可信包装与本人模型管道**，不是更多未授权 `.pth`。

---

## 5. 若做网站：和 08/09 App 怎么配套

App 策略不变：文件导入、无应用内名人货架。

网站若存在，只做管道，不做货架：

```
用户在电脑训好 / 有权使用的权重
    → 网站：校验元数据、可选转 ONNX、私有下载链
    → 手机 App：用系统「打开文件」导入
    → 本地转换与唱歌导出
```

不要做：站内按「周杰伦 / 某角色」浏览、排行、一键到 App。那就是 09 说的「把找模型做成平台」。

落地顺序仍先 App 闭环（08 §12），网站是附属；不要先堆一万个模型页再补转换器。

---

## 6. 不要做进 onlinefreetools.org

即便单独域名也要先定「只允许本人/授权上传」。挂到本站额外踩 Google 政策（见 `seo-google-policy`）：

- **Site reputation abuse**：第三方模型页主要借本站排名  
- **Scaled content**：按人名/角色名批量出近义下载页  
- 本站定位是可交互工具，不是权重仓库  

模型站若做，用 **另一域名、另一审核、另一法务**。本夹 01–04 的编辑器页仍不承载此事。

---

## 7. 结论

| 问题 | 答案 |
|---|---|
| 关站后还有人找模型吗？ | 有，HF + 聚合目录 + Discord。 |
| 再做社区明星模型站有空间吗？ | **流量有、产品空间无。** |
| 还有什么网站值得做？ | 自有模型托管 + ONNX 包装 + 授权/原创声线；先身份审核。 |
| 和 BYOM App？ | 网站是管道，App 是转换；货架两边都不做。 |
| 进本站吗？ | **否。** |

实现与竞品仍以 08、09 为准。本篇只回答「模型网站」这一刀。
