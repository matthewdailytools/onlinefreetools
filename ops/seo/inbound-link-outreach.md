# 白帽入站获链月度清单

对齐 [策略 §7.3](../../docs/2026-07-28-google-seo-strategy-implementation.md) 与 [链接执行案](../../docs/seo/2026-08-09/link-strategy-execution.md)。  
**禁止**：买链、强制交换、目录灌链、PBN、关键词堆砌锚文本。

## 节奏

每月 **2–4** 次高质量触点（宁少勿滥）。

## 触点类型

| 类型 | 做法 | 优先资产 |
|---|---|---|
| Awesome / 资源列表 | 向主题相关 awesome-*、curated lists 提交真工具页 | 有公式+示例+本地处理的工具 |
| 教育 / 文档资源页 | 大学课程资源、文档站「工具」页、开源 README | YMYL 须有 disclaimer 的页勿夸大疗效 |
| 断链修复 | 搜索失效竞品/旧工具链，礼貌建议替换为本站等价页 | 同意图、IG 更强的页 |
| 社区自然提及 | 回答真实问题后附链接（非刷帖） | 解决具体任务的页 |

## 外展要点

- 说明本站增量（本地处理、公式、边界、多语言），勿只写「free online tool」。
- 建议锚文本：品牌（OnlineFreeTools）或自然描述；**不要求** exact-match。
- 一封一页；记录日期、URL、对方站点、结果。

## 监控

- GSC → 链接报告：新引用域名是否自然。
- Disavow **仅**在 Manual Action 或明显 spam 攻击时使用。

## 当月记录模板

```markdown
## YYYY-MM
- [ ] 触点 1：类型 / 目标站 / 本站 URL / 日期 / 结果
- [ ] 触点 2：
- [ ] 触点 3：
- [ ] 触点 4：（可选）
```
