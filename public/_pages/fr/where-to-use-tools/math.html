Maths & stats tools

Math, statistics, and school helpers: means, equations, GPA, sample size, and geometry.

Calculateur de cercle

Sans envoi

Calculez l’aire du cercle (πr²) et la circonférence (2πr) à partir du rayon. Exemple : r=7 → aire ≈153.94, circonférence ≈43.98. Calcul local ; vérifiez la formule.

Calculateur d’intervalle de confiance — Comment calculer un IC

Sans envoi

IC de moyenne à partir de moyenne, SD, n et niveaux 90/95/99 avec z. Exemple : moyenne 50, SD 10, n 100, 95 % → environ 48,04 à 51,96. Une seule page pour les niveaux. Dans le navigateur, pour apprendre.

Calculateur d’exposants — Comment calculer des puissances

Sans envoi

Calculez a^b avec l’exemple 2^10=1024. Signale Infinity pour de grandes magnitudes et NaN pour certaines bases négatives à exposant non entier. Dans le navigateur, avec logs et notation scientifique.

Calculateur GPA — Moyenne pondérée

Sans envoi

Calculez un GPA pondéré par crédits sur une échelle 4.0 à partir des points et crédits par cours. Exemple : A=4.0 (3 cr) et B=3.0 (3 cr) → GPA 3.5. Les échelles varient selon l’établissement ; usage éducatif dans le navigateur.

Calculateur de gradient — ∇f multivariable (dérivées partielles)

Sans envoi

Calculez le gradient ∇f d’un champ scalaire comme vecteur de dérivées partielles. Processus : dériver pour chaque variable, assembler ∇f, évaluer en un point. Démo f(x,y)=x²y+3y → ∇f=(2xy, x²+3) ; en (1,2) → (4,4). Utile en optimisation et descente de gradient ML.

Calculateur de logarithmes — Comment calculer des logs

Sans envoi

Calculez log₁₀, ln ou log_b(x) pour x>0. Bases perso via ln(x)/ln(b). Exemple : log₁₀(1000)=3. Domaine explicite (x>0, b>0, b≠1). Dans le navigateur.

Sans envoi

Sans envoi

p-valeur normale bilatérale à partir d’un z via approximation erfc. Exemple : z = 1,96 → p ≈ 0,05. Hypothèses normale standard et deux queues explicites. Dans le navigateur, pour cours et vérifications rapides.

Sans envoi

Calculez les permutations P(n,r) et combinaisons C(n,r) pour des entiers 0≤r≤n (formules factorielles). Exemple : n=5, r=2 → P=20, C=10. Calcul local ; processus de dénombrement clair.

Calculateur de Pythagore — Trouver le côté manquant

Sans envoi

Résolvez le côté manquant a, b ou c avec a²+b²=c². Exemple : a=3, b=4 → c=5. Entrez deux côtés positifs ; refuse les paires impossibles. Dans le navigateur.

Solveur d’équation du second degré

Sans envoi

Calculez les racines réelles de ax²+bx+c=0 et affichez le discriminant avec la formule quadratique. Exemple : a=1, b=-5, c=6 → racines 2 et 3. Calcul local ; processus algébrique clair.

Calculateur de taille d’échantillon — Comment estimer n

Sans envoi

Estimez la taille d’échantillon pour une proportion avec n = Z²·p·(1−p)/E². Choisissez 90/95/99 % (Z = 1,645/1,96/2,576), saisissez p et l’erreur E. Exemple : 95 %, p = 0,5, E = 0,05 → n ≈ 385 (ceil). Dans le navigateur.

Calculateur de notation scientifique — Comment convertir

Sans envoi

Convertissez décimaux ↔ notation scientifique a×10^b. Exemple : 12300 → 1,23×10^4. Accepte 1,23e4 et 1,23×10^4 à l’expansion. Affiche coefficient et exposant. Dans le navigateur.

Calculateur de chiffres significatifs — Compter et arrondir

Sans envoi

Comptez les chiffres significatifs d’une chaîne ou arrondissez à N. Les zéros de tête ne comptent pas ; les zéros finaux après la virgule oui. Exemple : 0,00304 → 3 ; 1234,56 à 3 → 1230 (1,23e3). Moitié loin de zéro. Dans le navigateur.

Calculateur de pente — Comment calculer la pente entre deux points

Sans envoi

Calculez la pente m=(y₂−y₁)/(x₂−x₁) entre deux points. Exemple : (1,2) et (3,6) → m=2. Refuse les verticales avec Δx=0. Dans le navigateur, pour l’algèbre.

Calculateur d’écart-type — Écart-type et variance

Sans envoi

Collez une liste de nombres pour obtenir l’écart-type et la variance en mode échantillon (n−1) ou population (n). Jeu classique 2, 4, 4, 4, 5, 5, 7, 9 → écart-type population = 2 (échantillon ≈ 2,14). Calcul dans le navigateur : les valeurs restent sur l’appareil, sans envoi au serveur.

Calculateur de score z — Comment calculer un score standard

Sans envoi

Convertissez un score brut en z avec z = (x − moyenne) / écart-type. Exemple : x = 85, moyenne = 70, écart-type = 10 → z = 1,5. Hypothèses d’échelle linéaire et écart-type > 0. Dans le navigateur, pour cours et vérifications.
