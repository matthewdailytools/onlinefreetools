BMI計算ツール — 体格指数の求め方

非アップロード

成人向けの体格指数（BMI）を式で算出します。手順：メートル法かヤード・ポンド法を選び、体重と身長を入力して計算し、一般的な成人区分と照合。例：70 kg・175 cm → BMI 約22.9（標準）。学習・ざっくり確認用で、診断ではありません。

BMR / TDEE 計算ツール — 1日の消費カロリーの目安

非アップロード

Mifflin-St Jeor・Harris-Benedict・Katch-McArdle で基礎代謝量（BMR）を推定し、活動係数を掛けて TDEE（1日の総消費カロリー目安）を出します。例：男性 70kg・175cm・30歳・Mifflin・活動係数 1.55 → BMR 約 1648.75、TDEE 約 2555.56 kcal/日。ブラウザ内で計算；学習用の目安であり、医療やダイエットの助言ではありません。

非アップロード

複利計算ツール — 将来価値の求め方

非アップロード

元本・年利率・年数・複利回数から複利の将来価値を計算します。式 A = P(1 + r/n)^(nt)、単利モードも選択可。例：元本10000・年利5%・10年・年1回複利 → 約16288.95。ブラウザ内で計算；学習用の試算であり、投資助言ではありません。

EMI / ローン返済額計算ツール — 月々の返済額の求め方

非アップロード

借入額・年利・年数から元利均等の EMI（毎月または隔週の返済額）、総利息、返済スケジュールを計算します。物件価格と頭金からも借入額を出せます。例：借入 100000・年利 6%・5年・毎月 → 返済額約 1933.28。ブラウザ内で計算；学習用の試算であり、融資や与信の助言ではありません。

開く

多変数の勾配 ∇f を計算 — 偏導関数ベクトル

非アップロード

スカラー場の勾配 ∇f（偏導関数のベクトル）を求めます。手順：各変数で偏微分し ∇f を組み立て、点で評価。デモ f(x,y)=x²y+3y → ∇f=(2xy, x²+3)；点 (1,2) で (4,4)。最適化や機械学習の勾配降下の説明に。

開く

粗利率の計算ツール — 粗利と粗利率を求める

非アップロード

売上高と売上原価（COGS）から粗利（売上総利益）と粗利率を計算し、金額と比率を同じ結果欄で確認できます。例：売上 10,000、原価 6,000 → 粗利 4,000・粗利率 40%。ブラウザ内で完結し、データは送信しません。学習用の例示であり、経営・投資助言ではありません。

限界収入の求め方 — MR計算ツール（公式 ΔTR / ΔQ）

非アップロード

限界収入の求め方：2点の数量と総収入から MR = ΔTR / ΔQ で計算します。手順：第1・第2段階の数量と売上を入力→ΔTR と ΔQ を求めて割る。例：数量10→11、売上1000→1080 → MR = 80。授業・復習向けの例示で、価格設定や投資の助言ではありません。

開く

パーセント変化の計算 — 旧値から新値への増減率

非アップロード

旧値と新値から増減率を計算します。手順：両方を入力し (新−旧)/旧×100 を適用して符号を読む。例：80→100 = +25%。売上の前月比や DAU・値付け向け。百分点（ポイント）とは別物で、ROI（投資対効果）の代替でもありません。

ROI（投資利益率）計算ツール — 計算式と例

非アップロード

単純ROIを (利益 − 費用) / 費用 × 100%、または (最終価値 − 初期) / 初期 × 100% で計算します。手順：費用と最終価値（または純利益）を入力し、税・手数料・期間の前提を確認します。例：費用1000、最終1300 → ROI 30%。学習用の例示のみで、投資助言ではありません。

平方フィート⇔平方メートル換算 — 物件・リフォーム向け

非アップロード

部屋の面積を平方フィートと平方メートルのあいだで換算します（物件・リフォーム向け）。手順：ft/m/in を選び、縦×横を入力し、面積を求めたあと NIST 係数 1 ft² = 0.09290304 m² で m² も表示。例：850 sq ft の部屋 ≈ 78.97 m²。
