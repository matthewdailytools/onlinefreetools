Калькулятор ускорения

Без загрузки

Рассчитайте постоянное ускорение a=(v−v0)/t при прямолинейном движении. Пример: v0=0, v=10, t=2 → a=5. Только в браузере; сверьте шаги и допущения формулы.

Калькулятор возраста от даты рождения

Без загрузки

Считайте календарный возраст от даты рождения и даты отсчёта (UTC). Пример: 2000-01-01 на 2026-08-09 → 26 лет, 7 месяцев, 8 дней.

Калькулятор соотношения сторон — расчёт и масштабирование

Без загрузки

Найдите упрощённое соотношение сторон по ширине × высоте и масштабируйте к целевой ширине (или высоте). Пресеты 16:9, 4:3 и 1:1 — опции на одной странице. Пример: 1920×1080 → 16:9; ширина 1280 → высота 720. Счёт в браузере; числа остаются на устройстве и не загружаются на сервер.

Калькулятор ИМТ — как рассчитать индекс массы тела

Без загрузки

Рассчитайте индекс массы тела (ИМТ) по формуле для взрослых. Шаги: выберите метрическую или имперскую систему, введите вес и рост, получите ИМТ и сопоставьте с распространёнными категориями. Пример: 70 кг и 175 см → ИМТ ≈ 22,9 (норма). Только для обучения и скрининга, не диагноз.

Калькулятор BMR и TDEE — оценка суточных калорий

Без загрузки

Оцените базовый метаболизм (BMR) по Mifflin-St Jeor, Harris-Benedict или Katch-McArdle и умножьте на коэффициент активности для TDEE. Пример: мужчина, 70 кг, 175 см, 30 лет, Mifflin, коэффициент 1,55 → BMR ≈ 1648,75 и TDEE ≈ 2555,56 ккал/сут. Расчёт в браузере; только для обучения, не медицинский и не диетический совет.

Калькулятор процента жира — оценка по обхватам

Без загрузки

Оцените долю жира по формулам обхватов ВМС США (вариант Army на той же странице). Пример: мужчина, рост 178 см, шея 40 см, талия 86 см → ~15,3 %. Расчёт в браузере; только для обучения — не медицинский совет и не диагноз.

Калькулятор точки безубыточности — объём для покрытия затрат

Без загрузки

Рассчитайте точку безубыточности в штуках и выручке по постоянным затратам, цене и переменным затратам на единицу. Показывается маржинальный доход. Пример: постоянные 10 000, цена 50, переменные 30 → 500 шт. и выручка 25 000. В браузере; только обучение, не бизнес- и не инвестиционный совет.

Калькулятор CAGR — среднегодовой темп роста

Без загрузки

Посчитайте CAGR по начальной стоимости, конечной стоимости и числу лет. Пример: 10 000 → 16 105,10 за 5 лет → около 10,00%. Считает в браузере; только учебная иллюстрация — не инвестиционный совет.

Калькулятор круга

Без загрузки

Рассчитайте площадь круга (πr²) и длину окружности (2πr) по радиусу. Пример: r=7 → площадь ≈153.94, длина ≈43.98. Только в браузере; сверьте формулу.

Калькулятор сложного процента — будущая стоимость

Без загрузки

Рассчитайте будущую стоимость по сложному проценту: сумма, годовая ставка, срок в годах и частота капитализации. Формула A = P(1 + r/n)^(nt); опционально простой процент. Пример: 10 000 под 5% на 10 лет при ежегодной капитализации → около 16 288,95. Расчёт в браузере; только для обучения, не инвестиционная рекомендация.

Калькулятор бетона — оценка объёма бетона

Без загрузки

Оцените объём бетона для плиты, колонны или цилиндра по длине, ширине и толщине (или диаметру и высоте). Пример: плита 5 м × 4 м × 0.1 м → 2.0 м³. Число мешков опционально: 0.015 м³ (или 0.45 фут³) на мешок — допущение указано на странице. Счёт в браузере; числа остаются на устройстве и не загружаются на сервер.

Без загрузки

ДИ среднего по среднему, SD, n и уровням 90/95/99 с критическими z. Пример: среднее 50, SD 10, n 100, 95% → около 48,04–51,96. Уровни на одной странице. В браузере для обучения.

Калькулятор скидки — Цена со скидкой

Без загрузки

Калькулятор EMI — платёж по кредиту

Без загрузки

Рассчитайте платёж EMI по сумме кредита, годовой ставке и сроку. Формула уменьшающегося остатка с графиком амортизации. Опционально цена и первоначальный взнос; ежемесячные или двухнедельные платежи. Пример: 100 000 под 6% на 5 лет, ежемесячно → EMI ≈ 1 933,28. Расчёт в браузере; только для обучения, не кредитная рекомендация.

Считайте степени a^b с примером 2^10=1024. Указывает Infinity при огромных величинах и NaN для некоторых отрицательных оснований с нецелым показателем. В браузере вместе с логарифмами и научной записью.

Калькулятор градиента — многомерный ∇f (частные производные)

Без загрузки

Калькулятор логарифмов — Как вычислить log

Без загрузки

Считайте log₁₀, ln или log_b(x) при x>0. Своё основание через ln(x)/ln(b). Пример: log₁₀(1000)=3. Явно указывает область (x>0, b>0, b≠1). В браузере для учёбы.

Калькулятор предельной выручки — Формула ΔTR / ΔQ

Без загрузки

Рассчитайте предельную выручку по формуле MR = ΔTR / ΔQ. Процесс: введите количество и общую выручку в двух точках, получите ΔTR и ΔQ, затем разделите. Пример: Q 10→11, TR 1000→1080 → MR = 80. Только для обучения — не совет по ценообразованию.

Калькулятор ROI — Как рассчитать рентабельность инвестиций

Без загрузки

Только учебная иллюстрация — не инвестиционный совет.

Калькулятор размера выборки — Как оценить необходимый n

Без загрузки

Оцените размер выборки для доли по n = Z²·p·(1−p)/E². Выберите 90/95/99% (Z = 1,645/1,96/2,576), введите p и погрешность E. Пример: 95%, p = 0,5, E = 0,05 → n ≈ 385 (ceil). В браузере для учёбы.
