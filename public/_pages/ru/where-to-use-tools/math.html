Калькулятор круга

Без загрузки

Рассчитайте площадь круга (πr²) и длину окружности (2πr) по радиусу. Пример: r=7 → площадь ≈153.94, длина ≈43.98. Только в браузере; сверьте формулу.

Калькулятор доверительного интервала — Как рассчитать ДИ

Без загрузки

ДИ среднего по среднему, SD, n и уровням 90/95/99 с критическими z. Пример: среднее 50, SD 10, n 100, 95% → около 48,04–51,96. Уровни на одной странице. В браузере для обучения.

Калькулятор степеней — Как вычислить a^b

Без загрузки

Считайте степени a^b с примером 2^10=1024. Указывает Infinity при огромных величинах и NaN для некоторых отрицательных оснований с нецелым показателем. В браузере вместе с логарифмами и научной записью.

Калькулятор GPA — средневзвешенный балл

Без загрузки

Считайте взвешенный GPA по шкале 4.0 из баллов курса и кредитов. Пример: A=4.0 (3 кредита) и B=3.0 (3 кредита) → GPA 3.5. Шкалы различаются по школам и странам; только для обучения в браузере.

Калькулятор градиента — многомерный ∇f (частные производные)

Без загрузки

Вычислите градиент ∇f скалярного поля как вектор частных производных. Шаги: дифференцируйте по каждой переменной, соберите ∇f, оцените в точке. Демо f(x,y)=x²y+3y → ∇f=(2xy, x²+3); в (1,2) → (4,4). Для оптимизации и объяснения градиентного спуска в ML.

Калькулятор логарифмов — Как вычислить log

Без загрузки

Считайте log₁₀, ln или log_b(x) при x>0. Своё основание через ln(x)/ln(b). Пример: log₁₀(1000)=3. Явно указывает область (x>0, b>0, b≠1). В браузере для учёбы.

Калькулятор среднего

Без загрузки

Рассчитайте среднее арифметическое, геометрическое или гармоническое по списку чисел. Пример: 1,2,3,4,5 арифметическое → 3. Только в браузере; выберите тип среднего под ваш процесс.

Без загрузки

Рассчитайте медиану и моду списка чисел после сортировки (середина; самое частое). Пример: 1,2,2,3,4 → медиана 2, мода 2. Только в браузере; быстрый статистический процесс.

Калькулятор p-value — Как рассчитать p-значение

Без загрузки

Двустороннее нормальное p из z через аппроксимацию erfc. Пример: z = 1,96 → p ≈ 0,05. Явно указывает допущения стандартной нормали и двух хвостов. В браузере для учёбы и быстрой проверки.

Калькулятор перестановок и сочетаний

Без загрузки

Рассчитайте размещения P(n,r) и сочетания C(n,r) для целых 0≤r≤n по факториальным формулам. Пример: n=5, r=2 → P=20, C=10. Только в браузере; процесс подсчёта с/без порядка.

Калькулятор Пифагора — Как найти недостающую сторону

Без загрузки

Найдите недостающую сторону a, b или c по a²+b²=c². Пример: a=3, b=4 → c=5. Введите две положительные стороны; невозможные пары отвергаются. В браузере для учёбы.

Решатель квадратного уравнения

Без загрузки

Рассчитайте вещественные корни ax²+bx+c=0 и покажите дискриминант по квадратной формуле. Пример: a=1, b=-5, c=6 → корни 2 и 3. Только в браузере; понятный алгебраический процесс.

Калькулятор размера выборки — Как оценить необходимый n

Без загрузки

Оцените размер выборки для доли по n = Z²·p·(1−p)/E². Выберите 90/95/99% (Z = 1,645/1,96/2,576), введите p и погрешность E. Пример: 95%, p = 0,5, E = 0,05 → n ≈ 385 (ceil). В браузере для учёбы.

Калькулятор научной записи — Как преобразовать

Без загрузки

Преобразуйте десятичные ↔ научную запись a×10^b. Пример: 12300 → 1,23×10^4. Принимает 1,23e4 и 1,23×10^4 при развёртке. Показывает коэффициент и показатель. В браузере для учёбы.

Калькулятор значащих цифр — Подсчёт и округление

Без загрузки

Подсчитайте значащие цифры в строке или округлите до N. Ведущие нули не считаются; конечные после десятичной — считаются. Пример: 0,00304 → 3; 1234,56 до 3 → 1230 (1,23e3). Половина от нуля. В браузере.

Калькулятор наклона — Как найти наклон между двумя точками

Без загрузки

Считайте наклон m=(y₂−y₁)/(x₂−x₁) между двумя точками. Пример: (1,2) и (3,6) → m=2. Отвергает вертикали с Δx=0. В браузере для алгебры.

Калькулятор стандартного отклонения — СКО и дисперсия

Без загрузки

Рассчитайте стандартное отклонение и дисперсию для выборки (n−1) или генеральной совокупности (n) по списку чисел. Пример: 2, 4, 4, 4, 5, 5, 7, 9 → σ = 2 для совокупности (для выборки ≈ 2,14). Расчёт в браузере: числа остаются на устройстве, без загрузки на сервер.

Калькулятор площади треугольника

Без загрузки

Рассчитайте площадь треугольника по основанию и высоте по формуле площадь = основание×высота/2. Пример: основание 10, высота 6 → 30. Только в браузере; понятный геометрический процесс.

Калькулятор объёма

Без загрузки

Рассчитайте объём ящика (L×W×H) или сферы (4/3 πr³) по подходящей формуле. Пример: ящик 2×3×4 → объём 24. Только в браузере; понятный процесс геометрии тел.

Калькулятор z-оценки — Как рассчитать стандартный балл

Без загрузки

Переведите сырой балл в z по z = (x − среднее) / СКО. Пример: x = 85, среднее = 70, СКО = 10 → z = 1,5. Явно указывает линейное масштабирование и СКО > 0. В браузере для учёбы и быстрой проверки.
