BMI 计算器 — 如何计算身体质量指数

不上传

用成人筛查公式在线计算身体质量指数（BMI）。流程：选择公制或英制单位，输入体重与身高，按公式算出 BMI，再对照偏瘦/正常/超重/肥胖等常见成人分类。示例：70 公斤、175 厘米 → BMI 约 22.9（正常）。本工具仅供学习与筛查参考，不能替代医疗诊断。

打开

多元函数梯度计算 — ∇f 偏导向量

不上传

计算标量场的梯度 ∇f（各偏导数组成的向量）。流程：对每个变量求偏导，组成 ∇f，再代入坐标求值。演示函数 f(x,y)=x²y+3y → ∇f=(2xy, x²+3)；在 (1,2) 得 (4,4)。用于最优化与机器学习梯度下降讲解，非两点斜率工具。

打开

边际收益计算 — 公式 MR = ΔTR / ΔQ

不上传

用离散公式 MR = ΔTR / ΔQ 计算边际收益。流程：输入两档产量与总收入，分别求 ΔTR 与 ΔQ 再相除得到结果。示例：销量 10→11，收入 1000→1080 → MR = 80。仅供教学演示，不构成定价、经营或投资建议。适合微观经济作业核对。

打开

百分比变化计算 — 旧值到新值的涨跌幅

不上传

根据旧值与新值计算涨跌幅。公式：(新值 − 旧值) / 旧值 × 100。流程：输入旧值、新值，求差后除以旧值再×100，显示增减。示例：80→100 = +25%。适合月营收环比、日活、调价；注意不是「百分点」，也不同于 ROI 投资回报率。

打开

投资回报率（ROI）计算 — 公式与示例

不上传

用公式（收益 − 成本）/ 成本 × 100%，或（最终价值 − 初始投入）/ 初始投入 × 100% 计算简单 ROI。流程：输入成本与最终价值（或净收益），并对照税、费用与时间等假设。示例：投入 1000，收回 1300 → ROI 30%。仅供学习演示，不构成投资建议。

BMI 计算器 — 如何计算身体质量指数

不上传

用成人筛查公式在线计算身体质量指数（BMI）。流程：选择公制或英制单位，输入体重与身高，按公式算出 BMI，再对照偏瘦/正常/超重/肥胖等常见成人分类。示例：70 公斤、175 厘米 → BMI 约 22.9（正常）。本工具仅供学习与筛查参考，不能替代医疗诊断。

多元函数梯度计算 — ∇f 偏导向量

不上传

计算标量场的梯度 ∇f（各偏导数组成的向量）。流程：对每个变量求偏导，组成 ∇f，再代入坐标求值。演示函数 f(x,y)=x²y+3y → ∇f=(2xy, x²+3)；在 (1,2) 得 (4,4)。用于最优化与机器学习梯度下降讲解，非两点斜率工具。

边际收益计算 — 公式 MR = ΔTR / ΔQ

不上传

用离散公式 MR = ΔTR / ΔQ 计算边际收益。流程：输入两档产量与总收入，分别求 ΔTR 与 ΔQ 再相除得到结果。示例：销量 10→11，收入 1000→1080 → MR = 80。仅供教学演示，不构成定价、经营或投资建议。适合微观经济作业核对。

百分比变化计算 — 旧值到新值的涨跌幅

不上传

根据旧值与新值计算涨跌幅。公式：(新值 − 旧值) / 旧值 × 100。流程：输入旧值、新值，求差后除以旧值再×100，显示增减。示例：80→100 = +25%。适合月营收环比、日活、调价；注意不是「百分点」，也不同于 ROI 投资回报率。

投资回报率（ROI）计算 — 公式与示例

不上传

用公式（收益 − 成本）/ 成本 × 100%，或（最终价值 − 初始投入）/ 初始投入 × 100% 计算简单 ROI。流程：输入成本与最终价值（或净收益），并对照税、费用与时间等假设。示例：投入 1000，收回 1300 → ROI 30%。仅供学习演示，不构成投资建议。

不上传

把房源或图纸上的平方英尺换成平方米（或反过来），方便看房与装修估料。流程：选英尺/米/英寸，输入长×宽，算出面积，再按 1 ft² = 0.09290304 m² 给出平方米。示例：850 平方英尺公寓 ≈ 78.97 m²，便于对照本地挂牌。
