# 01 — 工具方向讨论

> 对照 `docs/2026-07-28-tool-direction.md`。一条工具只标一个**主方向**（A / B / C），不要硬凑三维交叉。

## 候选一句话

- 工具做什么：一次选发版目录里的多个文件，算 SHA-256（可选 MD5），出表，可贴 SHA256SUMS 对照，导出 CSV 或 SUMS 文本。
- 谁在什么任务里用：发版、镜像站、下载页维护者要一份校验和清单，或核对别人给的 SUMS。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | 是（主） | Web Crypto `digest` + 分块读文件 + 表/CSV；相对单文件哈希页增量在批对照与导出 |
| **B** 场景桥接 | 部分 | 「发版校验」是场景，主能力仍是浏览器哈希 |
| **C** 行业专属 | 否 | 不是某一发行渠道专属规范页 |

**选定主方向**：A  
**次要互链参考**：`file-hash`（单文件/粘贴文本）、`file-metadata-analyzer`（元数据表不是校验和）

## 方向专属检查

### 若选 A

- 成熟度 / 推荐包：`crypto.subtle.digest`（SHA-256/SHA-1）；MD5 对齐 `file-hash` 懒加载 crypto-js
- Tier：0（SHA）+ 1（MD5 可选懒加载）
- CWV：MD5 芯片才加载；串行哈希；大文件分块避免一次读入
