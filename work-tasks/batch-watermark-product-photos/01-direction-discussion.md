# 01 — 工具方向讨论

> 对照 `docs/2026-07-28-tool-direction.md`。一条工具只标一个**主方向**（A / B / C），不要硬凑三维交叉。

## 候选一句话

- 工具做什么：一次选多张商品照片，共用同一套文字水印（锚点、短边百分比、透明度、角度），先预览一张再全部盖上，成功项打 ZIP。
- 谁在什么任务里用：电商运营给一整拍 SKU 图打版权字，避免逐张调位置。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | 是（主） | Canvas `fillText` + 相对锚点 + 队列 + ZIP；相对单张页增量在批处理规则 |
| **B** 场景桥接 | 部分 | 「商品图版权字」是场景，主能力仍是浏览器批量盖印 |
| **C** 行业专属 | 否 | 不是某一平台规范计算器 |

**选定主方向**：A  
**次要互链参考**：`add-watermark`（单张）、`image-compress`（压体积不是盖印）

- [x] 不是无增量机翻铺量
- [x] 不依赖偏离定位的重后端
