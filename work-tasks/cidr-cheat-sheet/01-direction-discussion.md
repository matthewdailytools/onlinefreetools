# 01 — 工具方向讨论

> 对照 `docs/2026-07-28-tool-direction.md`。一条工具只标一个**主方向**（A / B / C），不要硬凑三维交叉。

## 候选一句话

- 工具做什么：可点选的 IPv4 CIDR 速查表（/8–/32：掩码、通配符、主机数、CompTIA 常考列、/31/32 脚注），不是任意 CIDR 展开计算器。
- 谁在什么任务里用：备考 CompTIA / 日常查「/n 对应什么掩码」、搞清 CIDR 全称；兽医同形词需一句消歧。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | **是（主）** | 静态对照表 + 点选高亮；Tier 0 |
| **B** 场景桥接 | 弱 | 可链到计算器，本页是速查 |
| **C** 行业专属 | 弱 | CompTIA 列是吸收钩子，不是整站考试产品 |

**选定主方向**：A  
**次要互链参考**：`cidr-to-ip-range`（要展开具体块）、`private-cidr-ranges`（私网分类）
