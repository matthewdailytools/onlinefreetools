# 01 — 工具方向讨论

## 候选一句话

- 工具做什么：在浏览器里选两个文本文件，按行看出增删，不上传。
- 谁在什么任务里用：要对两个 `.txt` 导出/备份/配置快照，而不是粘贴大段文字。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | **是（主）** | FileReader + jsdiff；Tier 1 CDN |
| **B** 场景桥接 | 弱 | 文件→差异是同一能力，不是跨工具流水线 |
| **C** 行业专属 | 否 | |

**选定主方向**：A

## 红线自检

- [x] 不是仅改 title/slug 的空壳变体（无粘贴首屏；编码/BOM/二进制边界）
- [x] 不是无增量机翻铺量
- [x] 不依赖偏离定位的重后端
- [x] 长尾默认一带多：`.txt` / `.text` 同页；不拆 file diff 头词页

## 方向专属检查

### 若选 A

- 成熟度：FileReader + `diff@5.2.0`（与 text-diff 同 CDN）
- Tier：1
- CWV：库从 CDN 加载；超大文件软上限并提示
