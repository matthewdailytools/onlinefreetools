# 01 — 工具方向讨论

## 候选一句话

- 工具做什么：选两份 `.docx`，抽出可见段落文本后做 diff，标出文字增删。
- 谁在什么任务里用：合同/纪要/作业稿要对「字改了什么」，不需要修订轨。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | **是** | mammoth + jsdiff；Tier 1 |
| **B** 场景桥接 | 弱 | |
| **C** 行业专属 | 否 | 非法务专页 |

**选定主方向**：A

## 红线自检

- [x] 相对粘贴页有实质差异（docx 解析 + 样式丢弃边界）
- [x] 不是无增量机翻铺量
- [x] 不依赖重后端
- [x] 不拆「compare two documents」混 PDF 的 doorway

## 方向专属检查

### 若选 A

- 包：mammoth（抽 HTML/纯文本）+ jsdiff
- Tier：1；首屏拉 CDN
- 局限：加密/损坏 docx 失败；页眉页脚/样式不进结果
