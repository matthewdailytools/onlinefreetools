# 01 — 工具方向讨论

## 候选一句话

- 工具做什么：选两个表格文件，按单元格地址对比当前工作表，标出不同格子。
- 谁在什么任务里用：要对两份导出表/报价/名单，关心格子值而不是整文件二进制。

## 主方向判定

| 选项 | 是否匹配 | 理由 |

| **B** 场景桥接 | 弱 | |
