# 01 — 工具方向讨论

> 对照 `docs/2026-07-28-tool-direction.md`。一条工具只标一个**主方向**（A / B / C），不要硬凑三维交叉。

## 候选一句话

- 工具做什么：按公制/英制输入身高体重，计算成人 BMI 并映射常见分类区间。
- 谁在什么任务里用：用户健康自查、健身入门筛查（教育用途，非诊疗）。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | 是 | Tier 0 纯公式；存量计算器增强 |
| **B** 场景桥接 | 部分 | 可与未来 BMR/TDEE 互链，非本轮主叙事 |
| **C** 行业专属 | 否 | 通用筛查，非岗位专属工具 |

**选定主方向**：A  
**次要互链参考**：`how-to-calculate-percentage-change`、`square-feet`（catalog 现有）；未来 BMR/TDEE
