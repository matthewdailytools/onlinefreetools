# 01 — 工具方向讨论

> 对照 `docs/2026-07-28-tool-direction.md`。一条工具只标一个**主方向**（A / B / C），不要硬凑三维交叉。  
> **本次性质**：存量缺口增强（§C），非新产品立项。

## 候选一句话

- 工具做什么：显示访问本站时边缘所见的客户端公网 IP，并说明获取方式与局限。
- 谁在什么任务里用：排查网络/代理；确认 VPN 出口；开发者核对请求来源 IP。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | **是（主）** | 边缘/请求头解析展示；轻量开发者工具 |
| **B** 场景桥接 | 弱 | 「查我的 IP」是单步任务，非长工作流 |
| **C** 行业专属 | 否 | 通用网络诊断 |

**选定主方向**：A  
**次要互链参考**：`website-headers`、`markdown-to-html`

## 红线自检

- [x] 不是仅改 title/slug 的空壳变体（补边缘获取说明 + 代理/VPN 边界）
- [x] 不是无增量机翻铺量（并**减少关键词堆砌**）
- [x] 不依赖偏离定位的重后端
- [x] 长尾默认「一带多场景」（what is my ip / show my ip / 公网 IP 同页）

## 方向专属检查

### 若选 A

- 成熟度 / 推荐包：已上线；依赖 Cloudflare/边缘请求属性或等价头
- Tier（0 / 1 / 2）：**Tier 0**
- CWV / 懒加载注意：极轻；文案避免 title/description 同义词堆砌

## 结论

- 继续立项：是（**存量增强**）
- 建议 slug：`ip-address`（不改）
- 与已上线工具关系：**增强已上线页**；Related 维持 catalog
- 进入 `02-tool-info.md` 前仍缺的信息：无
