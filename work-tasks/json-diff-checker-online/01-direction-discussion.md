# 01 — 工具方向讨论

## 候选一句话

- 工具做什么：贴/载入两份 JSON，按路径列出增删改；默认忽略对象键顺序。
- 谁在什么任务里用：接口样例、配置快照、模型输出要对「值变了没」，不是当纯文本 diff。

## 主方向判定

| 选项 | 是否匹配 | 理由 |
|---|---|---|
| **A** 浏览器 JS 能力 | **是** | JSON.parse + 递归路径差；Tier 0 |
| **B** 场景桥接 | 弱 | |
| **C** 行业专属 | 否 | |

**选定主方向**：A

## 红线自检

- [x] 相对 text-diff 有独立规则（键序 / 路径 / 非法 JSON）
- [x] 不是无增量机翻
- [x] 纯客户端
- [x] YAML/XML 有意不满足，不拆近义 URL

## 方向专属检查

### 若选 A

- 无重库；可选忽略键序（默认开）；数组默认按列表下标
- Tier：0
