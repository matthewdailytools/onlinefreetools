# 01 — 方向讨论

**主方向**：A（本地处理、可交互、people-first 工具页）

对标邻近页 `make-srt-subtitles-from-an-audio-file`（同域 Whisper → SRT）。本页**不**做近义换皮：

| | 音频页 | 本视频页 |
|---|---|---|
| 主意图 | 本地**音频**人声 → `.srt` | 本地**视频**对白 → `.srt` |
| 主输入 | audio/*（可附带视频） | **仅 video/**；纯音频拒收并链到音频页 |
| 预览 | 音频控件为主 | **视频播放器**为主（对照口型/画面） |
| 次路径 | 可选麦克风口述 | **无**麦克风（视频任务不抢口述） |
| 样例 | 短 WAV | 短 MP4（同演讲音轨 + 画面） |
| SEO 主词 | audio to srt | **video to srt** / 视频生成字幕 |

红线：不做 YouTube 抓字幕、不烧录硬字幕（FAQ 有意不满足 → related / 说明）。
