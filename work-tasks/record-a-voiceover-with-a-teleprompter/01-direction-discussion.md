# Direction decision

主方向：**A — 浏览器 JS 能力工具**, audio/voice section A.3 in `docs/2026-07-28-tool-direction.md`.

A fits native microphone capture plus a readable scrolling script. B would imply a format-conversion workflow, which is not the user job. C would unnecessarily restrict a general narration task to one industry.

S8 from `docs/sound-editor/12-slug-hub-and-scene.md` follows the shipped S7 memo recorder. It needs a distinct interaction: script editing, rehearsal, adjustable scrolling and synchronized recording pause. It is not a renamed memo recorder. No camera, cloud transcript, AI voice or waveform editor is included.

Evidence reviewed 2026-09-15: A2Z Tools teleprompter combines prompting and optional audio recording; Screenrecording.app has a standalone prompter. Neither observation establishes exclusive features or search volume. See 02 for the URLs and deliberate limits.
