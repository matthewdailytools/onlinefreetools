## 候选一句话

- 工具做什么：输入 URL，拉取并展示 HTTP 响应头，便于调试缓存、安全与内容类型头。
- 谁在什么任务里用：站长/开发者核对线上响应头（CORS、CSP、Cache-Control、Server 等）。

## 主方向判定

| 选项 | 是否匹配 | 理由 |

| **A** 浏览器 JS 能力 | **是（主）** | 开发者工具；跨域拉取需 Worker/边缘配合（方向文档已列现有模式） |
| **B** 场景桥接 | 弱 | 可写「上线前核对头」场景，但核心是 HTTP 能力工具 |
| **C** 行业专属 | 否 | 非单一垂直行话 |

**选定主方向**：A
